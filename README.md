# ⚡ Telegram Private Video & Media Downloader (Pro Vault)

টেলিগ্রাম প্রাইভেট গ্রুপ বা চ্যানেল থেকে নিজের কেনা কোর্সের ভিডিও, ছবি, অডিও এবং লেকচার শিট হাই-স্পিডে ডাউনলোড করার জন্য একটি প্রিমিয়াম ওয়েব ড্যাশবোর্ড টুল।

---

## ✨ ফিচারসমূহ

- 🚀 **হাই-স্পিড ডাউনলোড:** `tgcrypto` (Native C Acceleration) সাপোর্ট।
- 🎬 **১০০% অরিজিনাল কোয়ালিটি:** কোনো কম্প্রেশন ছাড়া ভিডিও বিট-ফর-বিট আসল কোয়ালিটিতে সেভ হয়।
- 📑 **ক্যাটাগরি ফিল্টার:** ভিডিও, ছবি, ডক/PDF এবং অডিও আলাদা ট্যাবে দেখা যায়।
- 🔍 **রিয়েল-টাইম সার্চ:** গ্রুপ এবং ফাইলের নাম দিয়ে তাৎক্ষণিক খোঁজা।
- 📂 **এক-ক্লিকে ফোল্ডার ওপেন:** সরাসরি ব্রাউজার থেকে উইন্ডোজ ফাইল এক্সপ্লোরার ওপেন করার সুবিধা।
- 🔒 **নিরাপদ ও প্রাইভেট:** টেলিগ্রামের অফিসিয়াল MTProto API ব্যবহার করে, ডেটা কেবল আপনার নিজস্ব পিসিতে সংরক্ষিত থাকে।

## 🛠️ ব্যবহারের নিয়ম

### ১. লাইব্রেরি ইনস্টল করুন
```bash
pip install telethon flask FastTelethonhelper telethon-tgcrypto tgcrypto
```
অথবা সরাসরি `3_install_web.bat` ফাইলটি ডাবল ক্লিক করে ইনস্টল করুন।

### ২. কনফিগারেশন সেট করুন
1. `config.example.py` ফাইলটি কপি করে `config.py` নামে রিনেম করুন।
2. [my.telegram.org](https://my.telegram.org)-এ গিয়ে আপনার `api_id` এবং `api_hash` সংগ্রহ করে `config.py` তে বসান:
   ```python
   API_ID = 12345678
   API_HASH = "your_api_hash_here"
   PHONE_NUMBER = "+8801XXXXXXXXX"
   ```

### ৩. অ্যাপ চালু করুন
`4_run_web.bat` ডাবল ক্লিক করুন অথবা টার্মিনালে চালান:
```bash
python web_app.py
```
ব্রাউজারে যান: `http://localhost:5000`
